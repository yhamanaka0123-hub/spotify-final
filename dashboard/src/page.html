Method and limits

Pipeline (coordinated by code): prepare (SQLite, exact-text dedupe) → enrich (TypeSafe Jev: topic, intent, severity and sentiment for each distinct text; low-confidence cases capped at 1% go to a Claude Sonnet advisor) → verify (Claude Haiku relabels a blind random sample) → group (one issue per primary topic; Claude Haiku names each issue) → rank (code only) → recommend (Claude Sonnet writes the memo from saved aggregates only; code checks every cited number and ID).

Scope: all 660,622 source IDs are accounted for. A seeded random sample of distinct review texts covering 100,000 review IDs was classified, and identical texts reuse one validated result. The remaining rows are quarantined with an explicit reason. Reviews are self-selected public opinions. Cancellation language is stated intent, not observed churn, and there is no revenue or plan data.
